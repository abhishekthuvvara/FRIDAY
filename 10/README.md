# FRIDAY — AI Coding Assistant

## Phase 10 Verification (Testing Suite)
1. **Backend Tests**: Navigate to the `backend` folder and run `pip install -r requirements.txt`. Then run `pytest tests/` to execute the API security, rate-limiting, and validation tests.
2. **Frontend Tests**: Navigate to the `frontend` folder, run `npm install`, and then execute `npm test` to run the component tests using Vitest.
3. **Manual Tests**: Refer to `TESTING.md` for the complete matrix of 10 test cases required by the project specifications, covering UI interactions, Gemini code generation, debugging, and security behaviors.
