# FRIDAY ⚡ AI Coding Assistant

FRIDAY is a production-ready, specialized AI coding assistant designed primarily for Python programming. Developed as a comprehensive B.Tech Artificial Intelligence and Machine Learning capstone project, FRIDAY focuses on reducing AI hallucinations through backend Abstract Syntax Tree (AST) validation while providing a highly secure, developer-friendly, and responsive glassmorphism interface.

---

## 🚀 Core Features

- **Python-First Intelligence**: Generates, explains, debugs, and refactors Python code using the Google Gemini 1.5 Flash model.
- **AST Syntax Validation**: Automatically intercepts and validates generated Python code blocks via the backend using Python's native `ast` module. If syntax errors are detected, the backend autonomously prompts the AI to self-correct before presenting the code to the user.
- **Developer-Focused UX**: Features a modern dark-mode glassmorphism UI with full Markdown support, `vscDarkPlus` syntax highlighting, and one-click "Copy Code" functionality.
- **Secure Authentication**: Integrated with Supabase Auth for seamless and secure Google OAuth sign-in.
- **Multi-Tenant Data Isolation**: Uses PostgreSQL Row Level Security (RLS) to guarantee that users can only access their own conversation history.
- **Enterprise-Grade Security**: Implements server-side rate limiting (10 requests/minute/IP) using SlowAPI, strict Pydantic input validation, and JWT verification.

## Security & Performance Measures

- **Rate Limiting:** Integrated `SlowAPI` middleware limits users to 10 requests per minute, preventing automated abuse and managing LLM API quota consumption.
- **JWT Verification:** Every backend endpoint requires a valid JSON Web Token generated by Supabase, strictly verifying the user's identity before executing database queries or LLM generations.
- **Data Isolation:** Data privacy is enforced at the database level using Row Level Security (RLS) policies, ensuring strict tenant isolation between user sessions.
- **Graceful Error Handling:** The system translates deep technical failures (like 404 Model Not Found or 429 Too Many Requests) into clean, user-friendly UI alerts without crashing the React application.

## 💻 Local Setup & Installation

### Prerequisites

- Node.js (v18+)
- Python (3.8+)
- A Supabase Project
- A Google Gemini API Key

### 1. Clone the Repository

```bash
git clone https://github.com/abhishekthuvvara/FRIDAY.git
cd friday-ai-assistant
````

### 2. Database Initialization

1. Navigate to your Supabase project dashboard.
2. Open the **SQL Editor**.
3. Copy the contents of `database/migrations/01_initial_schema.sql` and run it to create the `conversations` and `messages` tables along with their RLS policies.
4. Run `database/migrations/02_add_validated_flag.sql` to add the AST validation tracking columns.

### 3. Backend Setup

```bash
cd backend
python -m venv venv

# Activate virtual environment
# On macOS/Linux:
source venv/bin/activate
# On Windows:
# venv\Scriptsctivate

pip install -r requirements.txt
```

Create a `.env` file in the `backend/` directory:

```env
GEMINI_API_KEY=your_google_gemini_api_key
SUPABASE_URL=your_supabase_project_url
SUPABASE_ANON_KEY=your_supabase_anon_key
ENVIRONMENT=development
FRONTEND_URL=http://localhost:5173
PORT=8000
```

### 4. Frontend Setup

```bash
cd ../frontend
npm install
```

Create a `.env` file in the `frontend/` directory:

```env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

## 🚀 Running the Application

**Start the Backend API:**

```bash
cd backend
source venv/bin/activate
uvicorn app.main:app --reload --port 8000
```

**Start the Frontend Development Server:**

```bash
cd frontend
npm run dev
```

The application will be accessible at `http://localhost:5173`.
