# FRIDAY — AI Coding Assistant

## Phase 7 Verification (Python Coding Features & Validation)
1. **Database Check**: Ensure you ran `01_initial_schema.sql` from Phase 4, AND now run `02_add_validated_flag.sql` in your Supabase SQL Editor to support the syntax validation UI.
2. **Backend Engine**: The FastAPI backend now uses `ast.parse` to extract and validate Python code blocks generated by Gemini. If Gemini writes invalid syntax, FRIDAY automatically catches it and asks Gemini to fix it before returning the response to you.
3. **Start Application**: Run both frontend (`npm run dev`) and backend (`uvicorn app.main:app --reload`). 
4. **Test Validation**: Ask FRIDAY to write a complex Python script. You will see a green "Syntax Validated" badge under the response if the backend successfully checked the code.
