# FRIDAY — AI Coding Assistant

A production-style AI coding assistant focused on Python programming, featuring a modern glassmorphism UI, secure authentication, code validation, and hallucination reduction.

## Phase 5 Verification (Chat UI)
1. Start the application (`npm run dev` in frontend).
2. Log in using Google Auth.
3. Verify the new Chat Interface:
   - Sidebar toggling.
   - Creating new mock chats and deleting them.
   - Expanding multiline chat input.
   - Submitting messages (mock responses provided for UI testing).
   - "Scroll to bottom" functionality on long threads.
   - The subtle Energy Core background.
